## Ingredients needed to make this

- 3D Printed Case ( 2 Parts, Top and Bottom )
- 4x M3x5x4 Heatset Inserts
- 4x M3x16 Screws
- 6x Cherry MX Switches
- 6x Cherry DSA Keycaps
- 1x EC11 Rotary Encoder
- 1x XIAO RP2040
