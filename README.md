- <a href="https://github.com/imtua/ImtPad/blob/main/IMG_1040.jpg"><b>3D Printed Case</b></a>
- 4x <a href="https://cnckitchen.store/products/made-for-voron-gewindeeinsatz-threaded-insert-m3x5x4-100-stk-pcs"><b>M3x5x4 Heatset Inserts</b></a>
- 4x <a href="https://store.roboticsbd.com/tools-accessories/1790-m3x16-flat-head-screw-pack-of-5-robotics-bangladesh.html"><b>M3x16 Screws</b></a>
